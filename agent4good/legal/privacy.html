Privacy notice

For the single-owner, self-hosted application.

Scope

This notice describes Agent4Good’s single-owner software. The person running your installation controls its hosting and configuration. Connected services depend on that configuration.

Access and security records

Owner login accepts a password, not a name or email address. The owner password lives in server configuration. The app stores session-token hashes, security tokens, expiry times, and hashed network addresses for login rate limits. An essential browser cookie keeps you signed in for up to 12 hours. Signing out removes the current session.

Workspace records

The app saves task titles, prompts, results, errors, attachments, and timestamps. It also saves plans, worker messages, approvals, tool inputs and results, schedules, memory, evidence, and usage estimates. These records support execution, recovery, and later inspection. They can contain personal data you include or ask tools to retrieve.

Storage and protection

Workspace records use the host’s database and artifact storage. Optional distributed hosting uses PostgreSQL and object storage. Vault credentials use encryption with separately managed keys. Other workspace content is not encrypted by the app. Host and backup protection depend on the installation.

Data sent outside the host

Configured OpenAI or Anthropic models receive task instructions and selected context needed for a model call. Optional tools send relevant requests to Brave Search, GitHub, Resend, or websites you authorize. Browser journeys may send form data and files to those websites. Hosting and storage providers can also process installation data. These are supported recipients, not a claim that every installation uses them.

Cookies and support

The reviewed software has no analytics SDK or advertising tracker. Any later analytics setup needs a notice update. Emailing appwrite@mail.tin.computer sends your address and message to the Tin-managed support mailbox. Do not include credentials or private task contents.

Keeping and removing data

Saved workspace history has no automatic general deletion schedule. Cancelling tasks preserves their records. There is no self-service account deletion button. The person running the installation must arrange removal from databases, artifacts, logs, and backups. Copies sent to external services require separate handling under those services’ processes. Contact your installation owner about access, correction, or removal; product support can help with software questions.
